- 装 `@wagq/lint-ox@0.1.2` + `oxlint@1.94` + `oxfmt@0.79`（peer 范围 `^1.90` / `^0.75`）。注意 lint-ox 自己会嵌套装一份 `oxfmt@0.75` / `eslint@10`，安装体积会到 900 包左右，属正常。

- **换行符**：加 `.gitattributes`（`* text=auto eol=lf`），否则 Windows autocrlf 检出成 CRLF，`format:check` 必挂。

## 事故：npm 安装被 pnpm 劫持

- `npm i -D @wagq/lint-ox ...` 结束后，node_modules 变成 pnpm 的软链布局（`node_modules/.pnpm` 538 项），根目录还多出 `pnpm-lock.yaml`，`npm ls --all` 一片 invalid。
- 恢复方式：`npm install --package-lock-only` 重生成锁 → 把 node_modules 逐个改名挪到 `D:\code\rn\_nm_old_1117`（整体 rename 被句柄占用，只能逐项 `Directory::Move`）→ `npm install` 重新装 909 包。
- 教训：**这个环境里对 node_modules 做批量删除会被 safe-delete 钩子拦住**（trash 报 "Some operations were aborted"），要清理就整目录 rename 挪走，别指望 rm -rf / npm ci。
- 残留：`D:\code\rn\_nm_old_1117` 是旧依赖副本，需要手动删。
